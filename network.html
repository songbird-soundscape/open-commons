      Add to the network

      This page is a public snapshot of Hub Space Commons. To add a book, hub, lab, organization, or a whole participating node:

      • Start a thread in Discussions with what you'd like to add and how it connects.
      • Or edit data/commons.json and open a pull request.

      You can explore and read the forum, but not add to the commons. Ask the owner to give you Contributor access.

      A joining node is a project, lab or community that connects its own work to the commons. A connection theme belongs to a joining node (pick it under “Connects to”) and names why its links exist. It is drawn as links, not as a node.
