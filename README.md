# The Open Commons of Learning

A philosophical framework for teaching, education, and research: self-knowledge, praxis, and universality, built from open access and growing through knowledge hubs.

**Live site:** https://songbird-soundscape.github.io/open-commons/

Everything here is open. Take any code, concepts, or text and adapt them for your own field, school, or hub.

## What's here

- `index.html`: the whole site in one file (no build step, no accounts, no tracking).
- `network.html`: Hub Space Commons, the full searchable network of participating nodes, hubs, works, people and organizations.
- `data/commons.json`: the network data. Edit it and open a pull request to add a node, hub, work or organization.

## Join in

- **Make a hub, join a hub, or link your lab:** start a thread in this repository's Discussions.
- **News and updates:** posted in Discussions.
